# Code of Conduct

## Our Pledge

We pledge to make participation in the Oak Agent Kit community a harassment-free, technical, and constructive experience for everyone, regardless of background, experience level, or identity.

## Expected Standards

- **Be direct and factual:** Ground technical discussions, bug reports, and pull requests in reproducible steps, transaction hashes, or test cases (`forge test`).
- **Protect user custody:** Never ask another contributor or user to share a private key, 24-word recovery phrase, wallet passphrase, `.oak/wallet.enc` file, or raw owner key.
- **No financial hype or solicitation:** Do not use issues, discussions, or pull requests to promote tokens, promise financial returns, or post unverified contract addresses.
- **Respect attribution and boundaries:** Preserve third-party protocol attributions and follow the repository license boundaries in [`LICENSE`](LICENSE) and [`LICENSE-PACKAGES.md`](LICENSE-PACKAGES.md).

## Unacceptable Behavior

- Harassment, personal attacks, doxxing, or discriminatory language.
- Posting phishing links, malicious recipes, disguised executables, or deceptive contract addresses.
- Publicly disclosing unpatched security vulnerabilities instead of using private vulnerability reporting.
- Attempting to trick users or agents into running `oak init` or `oak export` outside the owner's terminal or exposing key material in logs.

## Enforcement and Reporting

- **Security vulnerabilities:** Report privately at https://github.com/OakAgentKit/oak/security/advisories/new (see [`docs/security.md`](docs/security.md)).
- **Code of Conduct issues:** Report violations by contacting the maintainers via [@OakAgentKit](https://x.com/OakAgentKit) or through a private repository report. Maintainers may remove offending content and ban accounts that violate these standards.
